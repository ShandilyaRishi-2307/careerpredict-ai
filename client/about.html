Mission & Architecture

About CareerPredict AI

Democratizing transparent career readiness analysis with rigorous statistical machine learning and modern web technologies.

🎯 Project Purpose & Mission

Navigating tech job searches can often feel opaque and uncertain. Candidates frequently wonder which skills have the highest hiring leverage, whether additional certifications move the needle, or how to allocate limited preparation time.

CareerPredict AI was designed to provide transparent, explainable career assessments. Rather than relying on black-box heuristics, our system leverages an interpretable Logistic Regression model to compute exact placement probabilities and generate prioritized, actionable skill growth roadmaps.

🏗️ System Architecture & Workflow

1. Frontend & Client

Clean semantic HTML5, modern CSS3 with custom variables, and vanilla JavaScript client. Uses Supabase Auth client for authentication and Chart.js for data visualization.

2. Backend Express API

Node.js and Express RESTful API server implementing robust JWT/Supabase bearer token verification, modular service controllers, input sanitization, and dual-persistence storage.

3. Data Persistence

Dual-layer data strategy: connects seamlessly to MongoDB with Mongoose schemas, and includes an embedded in-memory persistence engine with file-backup fallback when external DB URIs are unconfigured.

4. Python ML Microservice

Scikit-learn Logistic Regression pipeline executing data transformations, feature standard scaling, and probability inference via Python microservice and native linear algebraic fallback.

⚡ Key Platform Highlights

  • 5-Step Multi-Step Assessment: User-friendly progress navigation capturing 20+ candidate dimensions.
  • Explainable Probability Scores: Breaks down both job probability ($P=1$) and complementary no-job probability ($P=0$).
  • Dynamic Recommendations: Calculates candidate strengths, weakness flags, and prioritized actionable steps.
  • Role-Specific Benchmark Analysis: Compares candidates directly against role benchmarks (Frontend, Backend, ML, DevOps, etc.).
  • Historical Snapshots: Full immutable snapshot storage to monitor trajectory and skill improvements over time.
