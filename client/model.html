Logistic Regression Model Architecture

An in-depth explanation of the mathematical formulation, feature engineering, training hyperparameters, and evaluation metrics powering CareerPredict AI.

1. Mathematical Formulation & Sigmoid Activation

CareerPredict AI uses a calibrated Logistic Regression binary classification algorithm. The model maps a continuous linear combination of candidate feature inputs to a probability bounded between 0.0 and 1.0 via the standard Sigmoid activation function:

$$ P(Y = 1 \mid X) = \sigma(z) = \frac{1}{1 + e^{-z}} $$
where:
$$ z = \beta_0 + \sum_{i=1}^{n} \beta_i \cdot x_i $$

Here, β0 represents the model intercept (bias), βi represents the learned coefficient for feature xi, and P(Y = 1 | X) yields the estimated probability that a candidate meets placement qualification standards.

4. Training & Data Preprocessing Pipeline

  • Standard Scaling: Numerical features (skills 0-100, years of experience, project counts) are zero-mean unit-variance normalized using StandardScaler.
  • Categorical Encoding: Degrees and fields of study are encoded using OneHotEncoder with handle_unknown='ignore'.
  • Regularization: Ridge (L2 penalty) regularizer with C=1.0 to prevent overfitting and ensure numerical stability.
  • Dual Fallback Engine: Node.js server automatically falls back to compiled internal linear algebraic evaluation if the Python child process encounters environmental timeouts.
